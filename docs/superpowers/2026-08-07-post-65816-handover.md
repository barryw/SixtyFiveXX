## The public surface is now gated at member level

`PublicSurfaceTests` pins `ExpectedPublicMembers` — **108 entries**, an exact set, asserted per packed
framework beside the existing type list. The two packed DLLs were measured to produce byte-identical
member sets, so one list covers both; the library has no `#if`. If that ever stops being true the
per-TFM theory is what says so, and the list splits then.

Signatures render through a `SignatureText` provider over the **same `MetadataReader` the type walk
already used** — still nothing loaded, still nothing resolved, still one code path for both TFMs.

**Three rendering decisions, each arrived at by measuring the output rather than by taste:**

- **Custom modifiers stay as `modreq(…)`/`modopt(…)`.** A first draft folded them back into the syntax
  that produced them and **silently erased the `init` on all three `Instruction` setters** — `init` is
  `modreq(IsExternalInit)` and nothing else. Deleting those special cases was both *less code and more
  fidelity*, which is the useful shape of that lesson. The `InAttribute` branch in the same draft turned
  out to be dead code: `in` never reaches `GetModifiedType`, it arrives on the parameter row.
- **By-ref parameters and returns are qualified `in`/`out`/`ref`** from the parameter rows —
  `ParameterAttributes.Out`, and `IsReadOnlyAttribute` for `in`, with sequence number 0 carrying a
  `ref readonly` return. The signature blob only says "by ref"; a bare `&` cannot tell `Decode`'s
  `in TBus` from `Deconstruct`'s `out string`, and each swap is source-breaking.
- **Accessors appear under their generated names** (`get_Mnemonic()`), read from `GetMethods` rather
  than through the property and event tables. The accessor is what a consumer calls, and a property
  whose accessor is private would be reported by a property-level walk as callable when it is not.

**The gate was mutation-checked, not merely observed green.** Three mutations, each restored with
`git checkout --`, all run after committing first:

| Mutation | Result |
| --- | --- |
| Add a public `Disassembler.MutationProbe(int)` | **Caught.** The type-level theory was run against the *same* mutation and **stayed green** — the phase 7e hole, reproduced and then closed. |
| `readonly record struct Instruction` → `record struct` (`init` becomes `set`) | **Caught**, as `modreq(IsExternalInit) void` → `void`. The folded draft would have missed this. |
| `Decode`'s `in TBus` → `ref TBus` | **Caught**, as `in TBus` → `ref TBus`. It also failed to compile at `RoundTripTests.cs:244`, because `new FlatBus(ram)` is a temporary and cannot be passed by `ref` — a second, independent demonstration that the swap is breaking. |

The first mutation attempt proved nothing and is worth knowing about: it failed **for the wrong reason**.
`dotnet pack` inside the test died on `CS1591` (missing XML doc, an error in this build), so the test
went red without ever reaching the set comparison. **A mutation probe against this suite needs a doc
comment on the mutation**, or the red tells you nothing.

**Research gaps still open**, recorded honestly across phases: §12's four decimal-mode gaps, §13's two,
and the rows in §14.9 and §15.5. Nothing shipped depends on them.

## Things established that would cost real time to rediscover

**64tass emits the shortest encoding that fits a value.** `LDA $0012` assembles to `a5 12` — direct page —
not the three-byte absolute it was written as, and `LDA $001234` collapses to absolute rather than long.
The forcing prefixes are `@b`, `@w`, `@l`. This was a **live defect in all six cores' disassembly, latent
since phase 6a**: 53 opcodes on each NMOS part and 42 on each 65C02 rendered text that reassembled into a
different instruction.

**Assembler spellings belong in the harness, not the library.** `RoundTripTests`' `RMB0` → `rmb 0,`
handling states it: *"The encodings are identical, so this is a spelling, and it belongs here rather than
in the library."* Phase 7e briefly put `@w` into `Instruction.Operand` and it was reversed — partly on
that precedent, partly because the phase 6b sim6502 adapter builds its trace line from `Decode`'s operand
and would have displayed dialect text to users. **The reversal also fixed a bug the library-side version
had missed**, because the harness rule sees rendered text and never learns what a `NOP` is.

**The emulation-mode stack wrap is per-instruction, not per-address.** Clark §5.22: *"For all interrupts
and 'old' instructions, when the e flag is 1, the address of the data for an 8-bit push is `0,1,SL` …
Otherwise, … `0,S`."* Expressed as `Cpu.StackWrapsInPageOne`. The rule is scoped to **instructions**, not
addressing modes — which is why `JSR (abs,X)` wraps despite `(abs,X)` being new to the part.

**Four places a published source is demonstrably wrong**, all in research §3: Eyes & Lichty on the `m`/`x`
bit positions and on indexed-read timing; Clark §6.1.3 on `ASL`'s carry-bit polarity and §6.3.1 on the `b`
flag's position; and **the WDC datasheet's own Table 5-7 rows 2a/2b**, which print `VPA` where all 40,000
vectors read `VDA`. Consult §3 before trusting any single source.

## Traps that have each cost real time

- **The conformance suite needs an explicit 600000 ms timeout on the Bash call.** The default 120 s
  silently auto-backgrounds the run; that stalled one task with its whole tree uncommitted.
- **Commit before running any probe or mutation.** Two separate implementers across two phases lost
  uncommitted work to `git checkout --` during a mutation check. One recovered only from context.
- **Restore probe files with `git checkout --`, never `mv file.bak file`** — the latter preserves an old
  mtime and defeats MSBuild's staleness detection, which cost one task two phantom failures.
- **A stale incremental build looks exactly like a real conformance failure.** One task chased a red
  `AbsoluteOperandsBelowTheCollapseBoundary_RoundTrip` that cleared on deleting `obj`/`bin`.
- **`git commit -m` with a message containing double quotes will break the shell and abort the chain.**
  Use `git commit -F <file>` or a heredoc. `git merge -F -` does **not** read stdin — it needs a real file.
- **The `task-brief` script writes a fixed filename** and will silently overwrite a previous phase's
  brief. Rename to a phase prefix immediately after extracting.
- **A global find-and-replace across a plan file will renumber every task's steps, not just the one you
  meant.** Scope the edit to the section.
- **`Cpu`'s constructor never calls `Reset()`, so `P == $00` and both width flags read clear.** Any test
  meaning to discriminate `m` from `x` must set them to **opposed** values explicitly.
- **Coverage counts are not text.** The round-trips pin how many opcodes are unambiguously encodable, not
  what they render as. Proving rendered output unchanged needs a probe that decodes every opcode at both
  revisions and compares — that method caught nothing here, but only because it was run.
- **A mutation that fails to build is not a passing mutation check.** The first probe against
  `PublicSurfaceTests` went red on `CS1591` from the test's own `dotnet pack`, never reaching the
  assertion. Read *why* it is red before believing it.
- **A decomposition that sums correctly can still be wrong in every term.** `1,309 + 512 + 1 + 6 = 1,828`
  stood in this file for a phase; the real numbers are `1,290 + 513 + 12 + 8 + 5`. Count with
  `--list-tests`, do not cite.

## The process that produced this

Seven phases, each: `superpowers:brainstorming` → a spec section → `superpowers:writing-plans` →
`superpowers:subagent-driven-development` on a branch, fresh implementer per task, a reviewer after each,
one whole-branch review at the end, then `superpowers:finishing-a-development-branch`.

**Task 1 of every phase was research-only, and that is the single highest-value practice here.** Every
phase that did it got its vectors green on the first run. The honesty rule that went with it — *where a
source is silent, record the silence in those words* — turned up findings that repeatedly mattered more
than the code.

**Reviewers earned their cost by measuring rather than reading.** Across 7d and 7e they re-derived opcode
counts against the real code, reproduced 64tass byte counts with their own harnesses, proved rendered-text
identity by hashing 183,040 lines, and confirmed JIT folding by reading disassembly. They caught a false
research citation, two false measured claims, a surviving mutant, a cross-task defect neither task could
see, and an error in an instruction the controller had written.

**Several times the right answer was to reverse a decision already taken.** The `@w` placement was decided,
implemented, then reversed on evidence that arrived afterwards. Implementers twice refused a
brief-mandated test because the brief had gone stale, and were right both times. A plan is a starting
point; the measurement wins.
